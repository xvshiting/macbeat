A FEW GOOD QUESTIONS

Can it start and stop automatically every day?+

Yes. Open Daily plan, arrange multiple windows on the 24-hour dial, and save. Move or resize arcs; overlaps offer a merge preview. For overnight work, use 22:00–24:00 and 00:00–02:00 windows. MacBeat must be running and cannot wake a sleeping or shut-down Mac. Waking within an unused window starts a session until the original end time. After a stop or failure, that window is not retried. Existing manual sessions take priority.

Will my screen stay on?+

No. MacBeat keeps the system awake, but allows the display to turn off. Lock on lid close is enabled by default during closed-lid sessions: the session locks, the display can turn off, and reopening shows the macOS unlock screen. You can turn this off in Settings. A dark screen alone does not mean your tasks have stopped.

Does it work on every Mac?+

The download is for Apple silicon, with a macOS 13 minimum build target. Closed-lid operation has been physically verified on one MacBook Pro configuration. Other OS versions and setups need testing; no Intel binary is currently published.

Does it change my permanent sleep settings?+

Ordinary sessions use temporary requests and do not change persistent power settings. The separate Restore normal sleep action asks for administrator authorization to reset global restrictions and disabled idle-sleep timers. Other apps’ live requests remain listed until they release them. Closed-lid control uses shared system state, so avoid running multiple lid-control utilities together.

What happens when the timer finishes?+

MacBeat releases its keep-awake requests. Your Mac returns to its normal sleep policy; the app does not force immediate sleep.

Why did you build it?+

We expected to find an existing app that fit our workflow. After trying the options, we still wanted something simpler: a lightweight menu bar app, a clear end time, and closed-lid operation we could test ourselves. So we built MacBeat.
